Usage:

The easiest way to run this script is to write the map in a separate file and pass it as input to the script.

I.e. `python3 sokoban.py < mymap.in` in Mac OS / Linux / WSL / etc

Sample run:

Input
```
....####
..###..#
###....#
#O..X#.#
#OOX.X.#
###O.XS#
..###..#
....####
```
